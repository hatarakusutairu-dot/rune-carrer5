# rune-carrer5

高校eスポーツコース向け 60分授業進行アプリ

## 概要

高校eスポーツコースの初回授業（60分）で使用する、授業進行支援アプリです。
ゲーム的体験を通じて生徒が自分の「強みの芽」を発見し、この1年で育てたい力を
自分の言葉で見つけられるよう設計しています。

## 最重要設計方針

- **Kahootに依存しない**：Kahootが動作しなくてもアプリ単体で授業が成立する
- **300名同時参加に耐える**：診断処理は各端末で完結。サーバー処理を最小化
- **個人情報を保存しない**：ログイン・名前入力なし。localStorageで一時保存のみ
- **断定しない診断**：「あなたは〇〇な人」ではなく「今日の選択では〇〇の傾向」

## アプリの3モード

1. **講師モード**：スクリーン投影用、進行管理・タイマー・QR表示
2. **生徒モード**：スマホ/PCアクセス、ミニゲーム回答・診断結果表示
3. **フォールバックモード**：通信不安定時、講師画面のみで進行可能

## 60分授業の流れ

| Stage | 時間 | 内容 |
|---|---|---|
| 0. Start | 0〜5分 | 今日のミッション |
| 1. Mini Game | 5〜20分 | 採用系ミニアプリ体験 |
| 2. Result | 20〜27分 | 強みの芽診断 |
| 3. Share | 27〜34分 | ペア・グループ共有 |
| 4. Reveal | 34〜42分 | 今の採用とつなげる |
| 5. Skill Link | 42〜52分 | ゲームで育つ力と社会で活きる力 |
| 6. My Quest | 52〜60分 | この1年で育てたい力 |

## 最終ゴール

授業後に生徒が次のように感じられること。

- ゲームは無駄ではない
- ゲームで育つ力は社会にもつながる
- この高校で過ごす時間には意味がある
- この1年、自分の強みを育ててみよう
