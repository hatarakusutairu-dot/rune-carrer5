# 60分授業 Stage詳細仕様

最終更新：2026-04-28

各Stageは「講師画面」「生徒画面」「フォールバック動作」の3観点で定義する。

---

## Stage 0：Start / 今日のミッション

**時間：0〜5分**

### 目的
授業の安心感をつくる。「正解・不正解はない」「うまい下手を見る時間ではない」と
明確に伝える。

### 講師画面表示
- タイトル「今日のミッション」
- メッセージ：
  - 正解・不正解はありません
  - ゲームのうまい下手を見る時間ではありません
  - 自分の強みの芽を見つける時間です
- 参加用QRコード（大きく表示）
- 残り時間タイマー
- 次へボタン

### 生徒画面表示
- 「ようこそ」メッセージ
- 「準備OK」ボタン
- 注意書き：個人名は入力しません

### フォールバック
- 生徒がアプリに入れない場合、講師画面のメッセージを口頭で伝える
- QRが読めない生徒には、隣の人と同じ画面を見てもらう

## Stage 1：Mini Game / 採用系ミニアプリ体験

**時間：5〜20分（15分）**

### 目的
ゲーム的体験を通して、自分の選び方・考え方の傾向を知る。
**この時点では診断結果を見せすぎない**。

### ミニゲーム例（複数からピックアップ）

#### Game 1：チームの選択
> 5人パーティでボス戦に挑む。あなたが選ぶ役割は？
- A：先頭で攻撃を引き受ける（リーダーの芽）
- B：味方を回復・支援する（サポートの芽）
- C：敵の弱点を分析して指示を出す（分析の芽）
- D：新しい戦略を試してみる（チャレンジの芽）

#### Game 2：負けたあとの行動
> ゲームで連敗した。次にすることは？
- A：すぐにもう一戦（チャレンジ）
- B：負けた理由を振り返る（分析）
- C：チームに「気にしないで」と声をかける（サポート）
- D：少し休んで気持ちを整える（バランス）

#### Game 3：新マップ実装
> アップデートで新マップが来た。あなたはまず？
- A：とりあえず突っ込んで覚える（チャレンジ）
- B：マップ構造を確認して動線を予想（分析）
- C：仲間と情報交換（サポート）
- D：毎日少しずつ攻略する（継続）

各ゲーム3〜5問を想定。1問あたり15〜30秒で回答。

### 講師画面表示
- 現在の問題番号 / 全体問題数
- 各問の文字数を大きく表示（投影でも見える）
- 残り時間ミニタイマー
- 「全員回答終わったら次へ」ボタン

### 生徒画面表示
- 問題文
- A〜Dの選択肢ボタン（タップしやすいサイズ）
- 進捗バー（5問中3問目など）
- 一つ前に戻るボタン

### スコアリング
6タイプ（チャレンジ/分析/サポート/リーダー/継続/バランス）に得点を加算。
各回答に対し、主タイプ+2、副タイプ+1。

### フォールバック
- A/B/C/Dを手で挙げて回答
- 講師が口頭で問題を読み上げ
- 集計はしない（個人内省として進める）

## Stage 2：Result / 強みの芽診断

**時間：20〜27分（7分）**

### 目的
自分の傾向を肯定的に受け取る。

### 強みの芽タイプ（6種）

| タイプ | キーワード |
|---|---|
| チャレンジの芽 | 新しさ・挑戦・行動力 |
| 分析の芽 | 観察・戦略・冷静さ |
| サポートの芽 | 思いやり・協力・気配り |
| リーダーの芽 | 引っ張る力・決断・責任感 |
| 継続の芽 | 粘り強さ・地道・積み上げ |
| バランスの芽 | 調整・全体感・落ち着き |

### 表示ルール
- スコア上位2タイプを併記
- **「あなたは〇〇な人です」と断定しない**
- 「今日の選択では、〇〇の傾向が見えました」と表現

### 講師画面表示
- 6タイプ一覧の説明
- 「複数のタイプが見える人もいます。それは強みです」と明示

### 生徒画面表示
- 上位2タイプのカード
- 各タイプの肯定的な説明文
- 「これだけが自分ではない」という補足
- 次へボタン

### フォールバック
- 講師画面で6タイプを順に紹介
- 生徒は手元のメモに「自分っぽい」と思うタイプをチェック

## Stage 3：Share / ペア・グループ共有

**時間：27〜34分（7分）**

### 目的
自己理解と他者理解。

### 講師画面表示（問い）
- 結果は自分っぽかった？
- 意外だったところは？
- ゲーム中の自分にも似ているところはある？
- 自分と違うタイプの人がチームにいたら、どんな場面で助かりそう？

### 生徒画面表示
- 上の問いを再表示
- ペアで2分話す → グループで3分話す（タイマー連動）

### Kahoot使用時
- タイプ分布や気づきをKahootで投票

### フォールバック
- 隣の人と話す
- 数名指名して全体共有

## Stage 4：Reveal / 今の採用とつなげる

**時間：34〜42分（8分）**

### 目的
ゲーム的体験が現実の採用・社会で使われていることを知る。

### 講師画面表示メッセージ
> 実は、ゲームのような課題は、企業の採用や人材理解の場面でも
> 使われることがあります。
>
> 見ているのは、ゲームのうまさではなく、
> どんなふうに考えるか、
> どう選ぶか、
> どう仲間と関わるかです。
>
> AI面接やアバター面接など、新しい採用の形も出てきています。
> ゲームやアバター、オンライン空間に慣れていることは、
> これからの社会では強みになる可能性があります。

### 生徒画面表示
- 同様のメッセージ（読み物形式）
- ページ送りボタン

### フォールバック
- 講師画面のみで進行可能（生徒画面なしでも完結する）

---

## Stage 5：Skill Link / ゲームで育つ力と社会で活きる力

**時間：42〜52分（10分）**

### 目的
ゲーム内の行動が育てる力 → 社会で活きる場面、の因果を理解。

### 接続マップ例

| ゲームでの行動 | 育つ力 | 社会で活きる場面 |
|---|---|---|
| 味方に声をかける | コミュニケーション力 | チーム作業・面接・接客 |
| 負けた理由を考える | 分析力・改善力 | 勉強の振り返り・仕事の改善 |
| アップデートに対応 | 適応力 | AI時代・デジタル社会への対応 |
| ボイチャで指示を出す | リーダーシップ | プロジェクト推進・部活運営 |
| 毎日ログインして練習 | 継続力 | 資格取得・スキル習得 |
| 役割を決めて連携 | 役割分担・協働力 | グループワーク・職場 |

### 講師画面表示
- 接続マップを大きく投影
- 講師が1〜2例を口頭で深掘り

### 生徒画面表示
- 接続マップをカード形式で表示
- 自分が共感する3つを選ばせる（任意）

### フォールバック
- 講師画面のみで紹介し、口頭でつなぐ

## Stage 6：My Quest / この1年で育てたい力

**時間：52〜60分（8分）**

### 目的
この高校で頑張る理由を、自分の言葉で見つける。

### 講師画面表示
- 「この1年で育てたい力を1つ選ぼう」
- カード作成手順を投影

### 生徒画面表示（My Quest Card 作成）
1. この1年で育てたい力（選択）
2. ゲームの中で意識したい行動（選択 or 自由入力）
3. 学校生活で意識したい行動（選択 or 自由入力）

### My Quest Card 表示例

```
私がこの1年で育てたい力は
「コミュニケーション力」です。

ゲームの中では
「味方への声かけ」を意識します。

学校生活では
「グループワークで一言は発言すること」を意識します。

この力は将来、
チームで働く力や面接で伝える力につながります。
```

### スクショ最適化
- 縦長のカードレイアウト
- ロゴ・装飾は最小限
- カラーはアクセシビリティ準拠

### フォールバック
- 紙にカードフォーマットを書いてもらう
- 講師画面のテンプレートをそのまま手書きで埋める

---

## Stage間の遷移

| 遷移 | 方法 |
|---|---|
| 自動進行 | 推奨時間に達すると講師画面に通知 |
| 手動進行 | 講師の「次へ」「戻る」ボタンで操作可 |
| 一時停止 | 全体タイマーを止める（休憩等） |

---

## 文言設計の原則

| 原則 | 具体例 |
|---|---|
| 断定しない | ×「あなたはチャレンジ型」 ○「今日の選択ではチャレンジの傾向」 |
| 否定しない | ×「サポートが弱い」 ○ 言及しない or 「他の芽もあります」 |
| 評価しない | ×「優秀な選択」 ○「そういう選び方もあります」 |
| 全員を肯定 | どのタイプも前向きに表現 |
| 将来とつなぐ | 「この力は将来〇〇につながります」 |
