# 60分授業 Stage詳細仕様

最終更新：2026-04-28（v2 - Kahoot式同期＋採用ゲーム7種に改訂）

各Stageは「講師画面」「生徒画面」「フォールバック動作」の3観点で定義する。
Kahoot式の同期進行を前提とし、生徒は講師のペースに追従する。

---

## Stage 0：Start / 今日のミッション

**時間：0〜5分**

### 目的
授業の安心感をつくる。「正解・不正解はない」「うまい下手を見る時間ではない」と
明確に伝える。

### 講師画面表示
- ルーム作成 → 6桁コード + QR + URL を大画面に表示
- クラス入力（カンマ区切り：例「梅田大,梅田小,名古屋」）
- 入室人数のリアルタイム表示（クラス別）
- 「クラスの森」アニメ（入室1人で🌱が1つ追加）
- 今日のミッション文言

### 生徒画面表示
- 6桁コード入力 → クラス選択（ボタン式）
- 「ようこそ」メッセージ
- ロビー画面で講師の開始を待つ
- 「これは正解探しではない」と明示

### フォールバック
- アプリ入れない生徒：講師画面のメッセージを口頭で伝える
- 同期失敗：ローカルモードに切替（個人診断のみ）

## Stage 1：Mini Game / 採用系ミニアプリ体験

**時間：5〜20分（15分）**

### 目的
**採用現場で実際に使われているゲーム型アセスメントの簡易デモ**を体験。
生徒の選び方・反応・意思決定の傾向に触れる。

### 進行モデル（全7ゲーム共通）

```
[ロビー]
   ↓ 講師「ゲーム◯ 開始」
[3-2-1 カウントダウン]
   ↓
[active：生徒プレイ]
   ↓ 時間切れ or 全員回答 or 講師「締切」
[results：集計演出 → グラフ]
   ↓ 講師「次へ」
[次ゲーム or Stage終了]
```

### ゲーム一覧

#### Game 1：Balloon Risk（風船リスク）
- 元ネタ：Pymetrics BART（Balloon Analogue Risk Task）
- ルール：タップで風船を膨らます。膨らむほど高得点、ただし一定確率で割れて0点。`STOP`で確定
- 風船3個（赤・黄・青）、各15秒
- 測定：リスク選好（チャレンジ↔バランス）

#### Game 2：Digit Span（数字記憶）
- 元ネタ：HireVue Games の作業記憶課題
- ルール：3〜7桁の数字が2秒表示 → 入力。徐々に長く
- 5問（3桁から1桁ずつ増加）
- 測定：短期記憶（分析）

#### Game 3：Card Decks（カード山）
- 元ネタ：Iowa Gambling Task（Pymetrics系）
- ルール：4つのデッキから1枚引く。デッキにより期待値が違う、引きながら学習
- 30回
- 測定：学習・意思決定（分析・継続）

#### Game 4：Emotion Match（感情認識）
- 元ネタ：Pymetrics 感情認識
- ルール：表情画像 → 感情を4択で選ぶ
- 8問
- 測定：対人感受性（サポート）

#### Game 5：Money Split（お金分配）
- 元ネタ：Dictator Game / Trust Game
- ルール：10コインを自分と他人にどう配分？
- 3シナリオ
- 測定：利他性・公平性（サポート）

#### Game 6：Stop Signal（信号反応）
- 元ネタ：認知抑制課題
- ルール：緑が出たら即タップ、赤は押さない
- 40試行
- 測定：自己制御（バランス）

#### Game 7：Pattern Match（パターン認識）
- 元ネタ：Arctic Shores 系
- ルール：図形列の次に来る図形を選ぶ
- 8問
- 測定：パターン認識（継続・分析）

### 講師画面表示
- 現在のゲーム名・問題数・残り時間
- 入室人数 / 回答済み人数のプログレスバー
- 集計演出ボタン（「結果見る」「次へ」「スキップ」）
- 全体/クラス別ビュー切替

### 生徒画面表示
- 講師ペースに同期したゲーム画面
- 自分の選択結果は端末内に保存
- 早終了したら「他のクラスメイトを待っています」+ 再挑戦ボタン

### スコアリング
6タイプ（チャレンジ/分析/サポート/リーダー/継続/バランス）に得点を加算。
ゲームごとに行動指標 → タイプ加算ロジックを定義。

### フォールバック
- Kahootが動かない：このアプリ単体で完結
- アプリも動かない：講師がゲーム概念を口頭で説明、挙手で代替

## Stage 2：Result / 強みの芽診断

**時間：20〜27分（7分）**

### 目的
自分の傾向を肯定的に受け取る。

### 講師画面表示
- 6タイプ一覧の説明
- クラス全体のタイプ分布（円→棒変形アニメ）
- クラス別タイプ分布の比較ビュー
- AI解説風カード：
  - 「最多タイプ：分析の芽（35%）」
  - 「意見が割れたゲーム：Money Split」
  - 「このクラスの特徴：考えてから動く傾向」

### 生徒画面表示
- 個人レーダーチャート（6軸）
- 上位2タイプのカード
- 各タイプの肯定的説明
- 「あなたの全部ではない」フォロー

### 表示ルール
- **「あなたは◯◯」と断定しない**
- 「今日の選択では◯◯の傾向」と表現
- 少数派タイプには「レアな芽です」フォロー

### フォールバック
- 講師画面で6タイプを順に紹介
- 生徒は手元のメモに「自分っぽい」タイプをチェック

## Stage 3：Share / ペア・グループ共有

**時間：27〜34分（7分）**

### 目的
自己理解と他者理解。

### 講師画面表示（問い）
- 結果は自分っぽかった？
- 意外だったところは？
- ゲーム中の自分にも似ているところはある？
- 自分と違うタイプの人がチームにいたら、どんな場面で助かりそう？

### 生徒画面表示
- 上の問いを再表示
- リアクションボタン使用可（共感・面白い等）

### Kahoot使用時
- タイプ分布や気づきをKahootで投票

### フォールバック
- 隣の人と話す
- 数名指名して全体共有

---

## Stage 4：Reveal / 今の採用とつなげる

**時間：34〜42分（8分）**

### 目的
**ここで講師が口頭で「実はこのゲーム、本当に採用で使われている」と語る**。
Stage 1の体験と現実の採用をつなげる。

### 講師画面表示メッセージ
> 実は、Stage 1でやったゲーム、本当に企業の採用で使われているものに似ています。
>
> - Pymetrics（風船・カード・感情認識）：JPMorgan、Unilever、LinkedIn等で導入
> - HireVue Games（数字記憶）：Vodafone、Hilton等で導入
> - Arctic Shores（パターン認識）：PwC、Deloitte等で導入
>
> 見ているのは、ゲームのうまさではなく、
> どんなふうに考えるか、どう選ぶか、どう仲間と関わるかです。
>
> AI面接やアバター面接など、新しい採用の形も出てきています。
> ゲームやアバター、オンライン空間に慣れていることは、
> これからの社会では強みになる可能性があります。

### 生徒画面表示
- 同様のメッセージ（講師ペースで進む）
- リアクション可

### フォールバック
- 講師画面のみで進行可能

---

## Stage 5：Skill Link / ゲームで育つ力と社会で活きる力

**時間：42〜52分（10分）**

### 目的
ゲーム内行動 → 育つ力 → 社会で活きる場面、の因果を理解。

### 接続マップ例

| ゲームでの行動 | 育つ力 | 社会で活きる場面 |
|---|---|---|
| 味方に声をかける | コミュニケーション力 | チーム作業・面接・接客 |
| 負けた理由を考える | 分析力・改善力 | 勉強の振り返り・仕事の改善 |
| アップデートに対応 | 適応力 | AI時代・デジタル社会 |
| ボイチャで指示を出す | リーダーシップ | プロジェクト推進・部活運営 |
| 毎日ログインして練習 | 継続力 | 資格取得・スキル習得 |
| 役割を決めて連携 | 役割分担・協働力 | グループワーク・職場 |

### 講師画面表示
- 接続マップを大画面投影
- 講師が1〜2例を口頭で深掘り

### 生徒画面表示
- カード形式で接続マップ
- 自分が共感する3つを選ばせる（任意）

### フォールバック
- 講師画面のみで紹介

---

## Stage 6：My Quest / この1年で育てたい力

**時間：52〜60分（8分）**

### 目的
この高校で頑張る理由を、自分の言葉で見つける。

### 講師画面表示
- 「この1年で育てたい力を1つ選ぼう」
- カード作成手順を投影

### 生徒画面表示（My Quest Card 作成）
1. この1年で育てたい力（選択）
2. ゲームの中で意識したい行動
3. 学校生活で意識したい行動

### My Quest Card 表示例

```
私がこの1年で育てたい力は
「コミュニケーション力」です。

ゲームの中では
「味方への声かけ」を意識します。

学校生活では
「グループワークで一言は発言すること」を意識します。

この力は将来、
チームで働く力や面接で伝える力につながります。
```

### スクショ最適化
- 縦長のカードレイアウト
- ロゴ・装飾は最小限
- カラーはアクセシビリティ準拠

### フォールバック
- 紙にカードフォーマットを書いてもらう

---

## Stage間の遷移

| 遷移 | 方法 |
|---|---|
| 自動進行 | 講師がペース管理（基本Kahoot式） |
| 手動進行 | 講師の「次へ」「戻る」「スキップ」ボタン |
| 一時停止 | 全体タイマーを止める（休憩等） |
| 緊急切替 | ローカルモードへフォールバック |

---

## リアクション

8絵文字：👍 ❤️ 😂 😮 🌱 🔥 👏 🎉

- 全Stageで生徒/講師が押せる
- 講師大画面に絵文字が左右からふわっと浮上
- 集計には影響しない

---

## 文言設計の原則

| 原則 | 具体例 |
|---|---|
| 断定しない | ×「あなたはチャレンジ型」 ○「今日の選択ではチャレンジの傾向」 |
| 否定しない | ×「サポートが弱い」 ○ 言及しない or 「他の芽もあります」 |
| 評価しない | ×「優秀な選択」 ○「そういう選び方もあります」 |
| 全員を肯定 | どのタイプも前向きに表現 |
| 少数派フォロー | 「クラスで1人なら、レアな芽。チームの貴重な存在」 |
| 将来とつなぐ | 「この力は将来〇〇につながります」 |
| 採用ゲームの種明かし | Stage 1ではせず、Stage 4で講師が口頭で伝える |
