## 4. 不具合報告テンプレート

不具合発見時は以下のフォーマットで「既知の課題」に追記。

```markdown
| E-XXX | YYYY-MM-DD | bug/task/improvement | 概要を1行で | 高/中/低 | open | 対応方針 |
```

### 重大度基準

| 重大度 | 基準 |
|---|---|
| 高 | 授業進行が止まる・データ損失 |
| 中 | 一部機能が使えない・UX低下 |
| 低 | 表示崩れ・微細な不具合 |

### 種別

| 種別 | 内容 |
|---|---|
| bug | 動作不具合 |
| task | やるべき作業 |
| improvement | 改善要望 |
| security | セキュリティ・プライバシー関連 |
| content | 文言・コンテンツ関連 |

## 5. 運用チェックリスト（授業前）

授業当日までに必ず確認するリスト。

### 5.1 環境確認
- [ ] デプロイ済み URL がHTTPSでアクセス可能
- [ ] QRコードが読み取れる
- [ ] 講師PCで投影テスト済み
- [ ] 学校Wi-Fiで実機テスト済み（可能なら）

### 5.2 機能確認
- [ ] 講師画面の全Stageが動作
- [ ] 生徒画面の全Stageが動作
- [ ] タイマーが正しく動く
- [ ] リセットが正しく動く
- [ ] フォールバックモードが動作

### 5.3 コンテンツ確認
- [ ] 全文言が断定的でないか
- [ ] 全タイプが肯定的か
- [ ] 誤字脱字なし

### 5.4 バックアップ
- [ ] 講師画面の代替進行プランを紙でも持つ
- [ ] アプリが完全停止した場合の口頭進行案を準備
